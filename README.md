# Two-Sentence Horror

Entry for the make.fun bounty
[u-suroto-two-sentence-horror-acea9253](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253)
($2, ends 27 Nov 2026 15:00 WIB).

## What it is

A tiny Python program. Running it writes one original two-sentence
horror story (256 characters) to `/output/entry.txt`, the file the
competition harness reads and its sealed scorer gates (UTF-8 text,
1–400 characters, exactly two sentences).

## Run

```sh
python3 main.py
```

Set `OUTPUT_DIR` to write somewhere else for a local test:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```

## The story

The tenant downstairs complained that I pace all night, so I
apologised — I work nights and haven't slept at home in a week.
After a pause, he said the footsteps stopped the moment I started
talking, and asked who was walking around my flat while we spoke.
